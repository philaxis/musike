## ADDED Requirements

### Requirement: B tv 셋톱박스에서 리모컨으로 쓴다
집의 B tv 셋톱박스에서 Musike를 서버의 집 안 주소로 열면 TV 화면(큰 글자, 방향키 이동)으로 보여야 하고, 리모컨 방향키·확인·뒤로만으로 보관함의 재생목록과 「내 음악」 앨범을 골라 틀 수 있어야 한다(MUST). 재생목록·즐겨찾기는 폰과 같은 것을 보여 준다. 셋톱박스에는 Tailscale을 깔지 않는다. 셋톱박스 기종이 앱 설치를 막거나 서버와 다른 네트워크에 있으면 그 사실을 사용자에게 알리고 이 요구는 별도 이슈로 넘긴다.

#### Scenario: 리모컨으로 재생목록 틀기
- **WHEN** TV에서 Musike를 열고 리모컨으로 「보관함 › 출근길」을 고른 뒤 확인을 누른다
- **THEN** 첫 곡이 TV에서 재생되고, 화면에 곡 이름·표지·진행 막대가 크게 보인다

#### Scenario: 폰에서 만든 재생목록
- **WHEN** 헤르메스로 '카시오페아 라이브'를 만든 뒤 TV의 Musike를 연다
- **THEN** 보관함에 '카시오페아 라이브'가 보인다
