## ADDED Requirements

### Requirement: 정해 둔 서버 폴더의 파일이 곡이 된다
서버는 `MUSIKE_LOCAL_DIRS`에 적힌 폴더들 안의 소리·영상 파일마다 곡 하나를 만들어야 한다(MUST). 파일을 복사·변환해 저장하지 않으며 그 폴더에 쓰지 않는다. 곡 번호는 `L`과 20자로, 같은 경로의 파일은 늘 같은 번호다. yt-dlp가 남긴 반쪽 파일(같은 이름의 합친 파일이 있는 `.f<숫자>.<확장자>`)은 곡이 되지 않는다.

#### Scenario: 앨범 mp4 폴더
- **WHEN** 서버가 `야마시타 타츠로` 폴더(앨범 mp4 61개)를 읽는다
- **THEN** 「내 음악 › 야마시타 타츠로」에 곡이 연도순으로 보이고, 「[1980.09.21] RIDE ON TIME (Lossless).mp4」는 제목 "RIDE ON TIME", 가수 "야마시타 타츠로", 연도 1980으로 보인다

#### Scenario: 디스크 사용
- **WHEN** 두 앨범 폴더(31GB)를 모두 읽은 뒤 서버의 데이터·캐시 폴더 크기를 잰다
- **THEN** 늘어난 것은 색인 파일과 표지 그림뿐이고 합쳐 수십 MB를 넘지 않는다

#### Scenario: HDD가 안 붙음
- **WHEN** `/mnt/backup8t`가 없는 상태에서 서버가 폴더를 훑는다
- **THEN** 그 뿌리는 「지금 못 읽음」으로 보이고, 재생목록에 든 그 곡들은 지워지지 않으며 유튜브 곡은 그대로 재생된다

### Requirement: 로컬 곡은 유튜브 곡과 같은 자리에 들어간다
로컬 곡은 검색 결과, 재생목록, 즐겨찾기, 최근 재생, 대기열에 유튜브 곡과 섞여 들어가고 같은 단추로 다뤄져야 한다(MUST). 검색은 로컬 곡을 「내 음악」 묶음으로 유튜브 결과보다 위에 보여 준다. 유튜브에만 있는 기능(라디오, 뮤직비디오 찾기, 유튜브에서 열기)은 로컬 곡에서 보이지 않는다.

#### Scenario: 섞인 재생목록
- **WHEN** 재생목록에 로컬 앨범 「Mint Jams」와 유튜브 곡 「Asayake」를 넣고 처음부터 튼다
- **THEN** 두 곡이 차례로 끊김 없이 이어서 재생되고, 목록에서 둘이 같은 모양의 줄로 보인다

### Requirement: 로컬 곡은 소리만 또는 영상째로 재생된다
영상 모드에서는 파일을 구간 요청으로 그대로 보내 되감기가 자유로워야 한다(MUST). 소리 모드에서 영상이 든 파일은 서버가 그 자리에서 소리만 떼어(재인코딩 없이) 보내고 디스크에 쓰지 않는다. 되감기는 그 지점부터 다시 떼어 보내며, 화면과 잠금화면의 위치·길이는 파일 전체 기준으로 보인다. 원래 소리 파일은 그대로 보낸다.

#### Scenario: 소리 모드 데이터
- **WHEN** 앨범 mp4 「RIDE ON TIME」(43분, 387MB)을 소리 모드로 끝까지 듣는다
- **THEN** 폰이 받은 양은 약 100MB 안팎이다

#### Scenario: 소리 모드 되감기
- **WHEN** 소리 모드에서 진행 막대를 30분 지점으로 끈다
- **THEN** 2초 안에 30분 지점부터 소리가 나오고 위치가 30:00 근처로, 길이가 43:10 근처로 보인다

#### Scenario: 맨 끝으로 건너뛰기
- **WHEN** 소리 모드에서 진행 막대를 곡 길이와 같거나 넘는 지점으로 보낸다(`?t=`가 길이 이상)
- **THEN** 서버는 마지막 1초만 보내고, 곡이 곧 끝나 다음 곡으로 넘어간다(처음부터 다시 보내지 않는다)

#### Scenario: 영상 모드
- **WHEN** 같은 곡을 영상 모드로 바꾼다
- **THEN** 앨범 표지 영상이 같은 지점부터 나온다

### Requirement: 화면이 꺼져도 소리 모드로 이어진다
소리 모드 재생 중 화면이 꺼지거나 다른 앱으로 넘어가도 재생과 다음 곡 넘김이 이어지고, 잠금화면·알림에서 재생·멈춤·다음·이전·되감기가 되어야 한다(MUST). 영상 모드에서 화면이 꺼지면 소리 모드로 바뀌어 이어진다.

#### Scenario: 안드로이드 크롬
- **WHEN** 안드로이드 크롬에서 로컬 곡 둘이 든 재생목록을 틀고 화면을 끈다
- **THEN** 1분 뒤에도 재생 중이고, 첫 곡이 끝나면 다음 곡으로 넘어간다
