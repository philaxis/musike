## ADDED Requirements

### Requirement: AI가 서버 API로 재생목록과 곡을 다룬다
레포 `AGENTS.md`에 서버 주소와, 로컬 곡 찾기(`GET /api/local?q=`), 재생목록 만들기·이름 바꾸기·지우기, 곡 넣기·빼기, 순서 통째로 바꾸기(`PUT /api/playlists/:pid/tracks`), 유튜브 재생목록 가져오기, 받아 두기를 curl 예시와 함께 적어야 한다(MUST). 사용자가 열어 둔 화면은 다음에 목록을 읽을 때 바뀐 내용을 보여 준다.

#### Scenario: 말로 재생목록 만들기
- **WHEN** 사용자가 에이전트에게 "카시오페아 라이브 앨범만 모아서 '카시오페아 라이브' 만들어 줘"라고 한다
- **THEN** 에이전트가 `AGENTS.md`대로 API를 불러 재생목록을 만들고, 사용자가 폰에서 새로 고치면 그 재생목록에 라이브 앨범들이 연도순으로 보인다

#### Scenario: 순서 바꾸기
- **WHEN** `PUT /api/playlists/:pid/tracks`에 기존 곡 번호를 다른 순서로 보낸다
- **THEN** 재생목록이 그 순서가 되고, 목록에 없는 번호가 섞이면 400으로 거절한다

### Requirement: 링크 하나로 곡을 바로 연다
웹 경로 `/play/<곡 번호>`는 로컬 곡이든 유튜브 곡이든 그 곡을 대기열 맨 앞에 넣고 재생해야 한다(MUST). 브라우저가 자동 재생을 막으면 큰 재생 단추를 보여 준다.

#### Scenario: yt-bulk 알림 링크
- **WHEN** yt-bulk가 받기를 끝내고 텔레그램으로 보낸 Musike 링크를 폰에서 누른다
- **THEN** Musike가 열리고 그 영상이 재생된다(또는 재생 단추 하나만 누르면 된다)
