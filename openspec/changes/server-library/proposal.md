# Proposal: 서버판 — 내 음악 폴더와 유튜브 재생목록을 한 플레이어에서

## Why

사용자는 리눅스 서버에 모아 둔 음악(야마시타 타츠로 앨범 61개, 카시오페아 앨범 44개 — 앨범 하나가 mp4 하나, 합쳐 31GB, 구글 드라이브 사본이 HDD에 있음)과 유튜브에서 받아 둔 영상, 유튜브·유튜브 뮤직 재생목록을 밖에서 폰으로 듣고 싶다(이슈 #1, 11-18). 사용자 말: "영상도 걍 음악처럼 같이 동질적으로 재생목록만들고, 백그라운드 재생되는 그런 앱", "용량아깝다"(뽑거나 복사하지 말 것), "재생목록만들고, 노래관리같은걸 ai가 손쉽게 해줘서 난 밖에서 걍 들을수있는", "유튜브 재생목록도 라우팅 … 광고 이런건 당연히 안나오게".

Musike(MIT, 포크 `philaxis/musike`)는 유튜브 쪽을 이미 다 한다: 서버가 yt-dlp로 받은 소리·영상을 저장 없이 넘겨주니 광고가 없고, 소리/영상 전환, 재생목록·즐겨찾기(`library.json`), 잠금화면 조작, PWA. 빠진 것은 서버의 내 파일과 유튜브 재생목록 가져오기다. Jellyfin(지금 영상 보관함용)은 유튜브를 못 다루고 안드로이드 앱의 화면 꺼짐 재생이 불안해서 이걸로 바꾼다.

## What Changes

- **내 음악(로컬 곡)**: 서버가 정해 둔 폴더들을 읽어 파일마다 곡 한 줄을 만든다. 복사·변환해 저장하지 않는다. 유튜브 곡과 똑같이 검색·재생목록·즐겨찾기·대기열에 들어간다. 「보관함」에 「내 음악」 칸(폴더 → 앨범 → 곡)이 생긴다.
- **로컬 곡 재생**: 영상 모드는 파일을 구간 요청으로 그대로 보낸다. 소리 모드는 서버가 그 자리에서 소리만 떼어 보낸다(저장 안 함, 1시간에 약 140MB, 영상째 보내면 약 540MB). 되감기는 그 지점부터 다시 떼어 보낸다.
- **유튜브 재생목록 가져오기**: 검색창에 유튜브·유튜브 뮤직 재생목록 링크를 넣으면 「재생목록으로 가져오기(N곡)」가 뜨고, 같은 이름의 재생목록이 생긴다. 다시 가져오면 빠진 곡만 더한다. 곡은 저장하지 않고 들을 때 받아 넘긴다.
- **서버에 받아 두기**: 유튜브 곡 메뉴의 「서버에 받아 두기」로 소리(m4a)를 HDD에 받아 둔다. 받아 둔 곡은 유튜브 대신 그 파일로 튼다(유튜브에서 지워져도 들림).
- **바로 열기 링크**: `/play/<곡 번호>`를 열면 그 곡이 바로 재생된다(yt-bulk 알림 링크용).
- **AI가 관리**: 레포 `AGENTS.md`에 서버 API로 재생목록 만들기·곡 넣고 빼기·순서 바꾸기·로컬 곡 찾기·유튜브 재생목록 가져오기를 하는 법을 적는다. 순서 바꾸기 API를 더한다.
- **서버 운영**: systemd 사용자 서비스 `musike`(:4180), PWA 설치용 Tailscale HTTPS 주소, 큰 캐시는 HDD.
- **한국어 화면**: 설정의 언어에 한국어를 더하고 서버판 기본값으로 둔다.
- **정리**: 다 되면 yt-bulk 알림 링크를 Musike `/play/…`로 바꾸고(yt-bulk 별도 PR) Jellyfin을 지운다.

## Capabilities

### New Capabilities

- `local-library`: 서버 폴더의 파일을 곡으로 보여 주고 트는 것.
- `youtube-playlist-import`: 유튜브·유튜브 뮤직 재생목록 링크를 재생목록으로 가져오기.
- `server-keep`: 유튜브 곡을 서버에 받아 두고 그 파일로 틀기.
- `agent-control`: AI가 서버 API로 재생목록과 곡을 다루는 방법과 바로 열기 링크.

### Modified Capabilities

(없음)

## Impact

- 서버: `types.ts`(곡 번호 규칙), `library.ts`, `app.ts`, 새 `local.ts`·`keep.ts`·`playlistImport.ts`, `stream.ts`
- 웹: `lib/api.ts`, `player/player.ts`(로컬 소리 되감기), 보관함·검색·곡 메뉴 화면, `/play/:id` 경로, 한국어 문구
- 안드로이드·iOS·데스크톱 앱 판은 이 변경에서 다루지 않는다(서버판 웹만).
- 운영: `~/.config/systemd/user/musike.service`, `tailscale serve`, yt-bulk 알림 링크, Jellyfin 삭제
