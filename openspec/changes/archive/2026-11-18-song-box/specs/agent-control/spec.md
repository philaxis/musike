## ADDED Requirements

### Requirement: 헤르메스가 곡 상자를 정리한다
헤르메스 기술 파일은 곡 상자 읽기(거르기·찾기), 꼬리표 붙이고 떼기, 묶음 만들기, 재생목록에 나눠 넣기 API와, "새로 들어온 거 정리해 줘" 흐름(정리 안 된 곡 → 꼬리표 → 알맞은 재생목록에 넣거나 새 재생목록 제안 → 무엇을 어디에 넣었는지 답장)을 담아야 한다(MUST). 매일 아침 헤르메스 cron 작업이 유튜브 가져오기 뒤 이 흐름을 돌린다.

#### Scenario: 말로 정리
- **WHEN** 사용자가 텔레그램에서 "새로 들어온 거 정리해 줘"라고 보낸다
- **THEN** 헤르메스가 정리 안 된 곡에 꼬리표를 붙이고 재생목록에 나눠 넣은 뒤, 재생목록별 곡 수와 열기 링크를 답한다

#### Scenario: 클래식 묶기
- **WHEN** 사용자가 "베토벤 5번 카라얀 거 한 곡으로 묶어 줘"라고 보낸다
- **THEN** 헤르메스가 그 악장들을 순서대로 묶음 하나로 만들고 `작품:베토벤 교향곡 5번`, `연주:카라얀` 꼬리표를 붙여 답한다
